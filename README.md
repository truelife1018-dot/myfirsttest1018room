# えいご まなびなおし

中学2年生が、中1・中2の英語を学び直すための家庭用Webアプリです。
目標は2028年2月の都立高校入試。くわしい設計は [SPEC.md](SPEC.md)（仕様書）を見てください。

## いまできること（第1〜3段階）

- 単元マップ（教科書「Here We Go!」の順番。クリアすると色がつく）
- うさぎ先生の説明 → 問題 → 解説 の流れ（1回 約10分）
- 問題の種類：選択・並べ替え・リスニング・読解・聞いてまねする（選択肢は毎回シャッフル）
- 中1の全範囲 Ready to Start 〜 Unit 8（19ステップ・190問）
- 学習記録の保存（このパソコンのChromeの中だけ）
- 診断テスト（全36ステップから1問ずつ・3回に分けて受ける。「できている」ステップに★）
- 自動復習（まちがえた問題を 翌日 → 3日後 → 1週間後 に出し直す。3回続けて正解でおわり）

## ネットに公開する手順（GitHub Pages・無料）

1. GitHubでこのリポジトリを開き、**Settings**（設定）を開く。
2. リポジトリが「Private（非公開）」なら、Settings の一番下 **Danger Zone → Change visibility** で **Public（公開）** にする。
3. 左のメニューの **Pages** を開く。
4. **Source** を「Deploy from a branch」にし、**Branch** でアプリが入っているブランチ（例：`main`）と `/ (root)` を選んで **Save**。
5. 数分待つと、同じ画面の上に `https://（ユーザー名）.github.io/（リポジトリ名）/` というURLが表示される。これをChromeで開き、ブックマークしておく。
